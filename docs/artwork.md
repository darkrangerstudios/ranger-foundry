This exact-file exception includes the reviewed provenance bytes; it does not
permit other images or arbitrary binary metadata. Normal path, mode, and symlink
checks still apply.

The hash detects byte changes; it does not replace content review. A replacement
requires a fresh visual and metadata review and a new hash in the same accepted
change. Run the validator with isolated Python imports as documented in the
README so repository files cannot substitute for standard-library modules.
